# My Budget Tracker

## Week 3: Visual Design Improvements

This project is a Budget Tracker designed to help users record and view their expenses in one place.

For Week 3, I improved the visual design of the existing Budget Tracker using CSS. I focused on color, typography, table and form styling, and the CSS Box Model.

## Color Palette

The project uses a consistent green color palette.

- Green is used for headings, buttons, and table headers.
- White is used for the main cards and form areas.
- Light gray is used for the page background and alternating table rows.

This creates a clean and consistent appearance throughout the application.

## Typography

The project uses Google Fonts:

- **Poppins** is used for headings and important titles.
- **Inter** is used for body text, labels, form inputs, buttons, and table content.

This improves readability and creates a clear visual hierarchy.

## CSS Box Model

The CSS Box Model is used throughout the project to organize the page and create clear separation between sections.

The project uses:

- **Margin** to separate sections.
- **Padding** to create space inside elements.
- **Borders** to define cards, forms, and tables.
- **Border-radius** to create rounded and modern elements.

The page heading, Add Expense form, and Expense Table are presented as separate visual cards.

## Table and Form Styling

The Add Expense form includes:

- Styled labels
- Input fields
- Category selection
- Date input
- Styled Add Expense button
- Consistent spacing and borders

The expense table includes:

- A green table header
- Proper cell padding
- Borders
- Alternating row colors
- Hover effects
- Rounded corners

## Technologies Used

- HTML5
- CSS3
- Google Fonts
